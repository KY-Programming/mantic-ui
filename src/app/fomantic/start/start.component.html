Install base package for angular and Fomantic UI theme

Import the theme components in your AppComponent

All components are standalone, import them where you use them.

Apply the style in your AppComponent

<m-fomantic-ui-theme dark> switches the components to their inverted variants, <m-fomantic-ui-theme auto> follows the dark mode setting of the operating system.

The theme is Fomantic UI 2.9.4 compiled from its LESS sources, plus the adjustments the mantic components need (icons rendered by m-icon, Font Awesome support, the check mark of m-checkbox). The plain Fomantic UI CSS from a CDN lacks those.
