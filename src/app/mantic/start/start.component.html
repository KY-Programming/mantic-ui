Install

Import the theme components in your AppComponent

Adjust the theme at runtime

Colors, radii, spacing, fonts and motion are CSS custom properties (--m-*). Change them for the whole page or for one part of it; hover, active and text-on-color variants follow automatically. Try it in the theming playground.

Browser support

The theme targets current browsers (2024 and newer): it relies on light-dark(), color-mix(), relative colors and cascade layers.
